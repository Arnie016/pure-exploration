# Garden structures

These two small GLB files come from Arnav’s existing Fab Assets library. They are original procedural Blender geometry, created with `generate_wind_shrine.py` and `build_five_assets.py` (the modular portal builder), then exported locally for this browser world.

- `wind-shrine.glb`: 7,152 triangles, five materials, animated chimes.
- `modular-portal-arch.glb`: 3,028 triangles, four materials, animated ring.

No Fab marketplace purchase, asset download, or marketplace license is represented by this import. The buildings, water shaders, gardens, and themed monuments in the lobby are original local geometry and code by Arnav with Codex.
