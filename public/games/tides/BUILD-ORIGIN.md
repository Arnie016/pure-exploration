# Tides of Infamy — Pure Exploration edition
Built from Arnav's existing Tides of Infamy source on 29 September 2026. The original checkout was not modified. Root-relative assets were namespaced under /games/tides/.

This is the solo browser edition. Multiplayer provider configuration was not loaded; cloud voice, account progression and external API routes are not connected. No environment file or provider credential is included.

Art, models, audio, and vendor materials retain their own notices; assets are not relicensed by the hub's source license. Three.js is MIT; bundled Kenney assets keep the notices shipped under assets/vendor.

Offline guidance integration: guided mode preserves route pins and text tutorial progression. Cloud voice settings are disabled even for saved preferences; realtime arm requests return locally before network access. Unavailable voice/shanty controls are hidden. The original source checkout is unchanged.
