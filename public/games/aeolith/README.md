# AEOLITH · Meridian Clash — AI practice presentation

This public browser build comes from Arnav’s latest local Meridian Clash source as inspected on 29 September 2026. It includes the 25 September ship-workshop and supertree work. It is separate from the older Sand Engine deployment at aeolith.vercel.app.

This is the explicit AI-practice build. Online matchmaking, remote authority, cloud progression and ranks are disconnected. The common Pure Exploration lobby has its own visitor presence; that is not AEOLITH multiplayer.

Only browser build output and previously public game assets are included. No local logs, credentials, .env files or owner data were copied. Network build variables were explicitly removed, and Vite environment-file loading was disabled. Existing local source files and deployment state were left unchanged.

The original game and the public asset provenance records retain their existing rights and credits.
