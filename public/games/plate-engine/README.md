# Plate Engine

The existing interactive geography laboratory created by Arnav in Claude Code, preserved here for exploration without an account.

Original published artifact: <https://claude.ai/artifact/1fQZBWsMsMsd4cPFzwGHdu>.

This is the original standalone laboratory, including its eight station views, mantle convection, fault rupture, ocean waves, arc and hotspot volcanoes, caldera, layers, seismogram and forecast controls. The scene uses illustrative units and compressed time; forecasts describe the toy model rather than actual hazards.

Hub integration changes are limited to document language and viewport declarations and replacing the remote Three.js script with the matching local Three.js 0.158.0 build. Fonts remain optional Google Fonts requests with system fallbacks. There are no API keys, server requirements or authentication requests.
