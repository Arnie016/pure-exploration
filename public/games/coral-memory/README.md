# Reef / Memory

An original procedural reef experiment by Arnav, recovered from the existing REEF/MEMORY project. Explore a simulated 2019–2026 history, select colonies, tag a genus, compare similar forms, and leave browser-local notes.

This is an illustrated simulation, not a real reef survey or a medical/ecological diagnosis tool. There are no remote collaborators or shared cloud notes in this edition. No account required.

Controls: drag to orbit, scroll/pinch to zoom, click a coral for its dossier, Space to play/pause time, T for the guided tour, N for night dive, P for photo mode and C to save a photo. The field guide explains the same controls in the scene. Sound is off by default.

`BUILD_ORIGIN.json` records source hashes and integration provenance. Adaptations include local dependencies, honest simulation labels, safe text-only notes, direct entry, reduced-motion behavior and space for the surrounding Pure Exploration controls.

## Dependencies

- Three.js r160, MIT; license in `vendor/LICENSE`.
- Big Shoulders Display, Schibsted Grotesk and Chivo Mono typefaces; SIL Open Font License texts in `fonts/`.
- Scene meshes, underwater shading and all reef forms are procedural. No external reef scan dataset is included.
