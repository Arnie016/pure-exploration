# The original Space-Time Lab

**Solar System Laboratory — Light Years From Home**, recovered from the current source associated with Arnav’s pinned “Spacetime Thought experiments” chat. This is the existing September 13 laboratory, not the replacement black-hole demonstration and not the older July archive.

The original Newtonian n-body simulation, JPL-pinned initial state, scenario editor, orbital controls, guided physics lessons, collision rendering, relativity experiments, and Schwarzschild light-path experiment are retained. Their computed/illustrative distinctions remain in the interface.

## Explore

Choose a system from the Scenario selector. Drag empty space to orbit and scroll to zoom; select a body, use F to frame it, or 7 for top view. Run/pause and time-flow controls sit on the lower rail. Experiments opens the original field, seasons, dark-matter, light-path and relativity controls. Simulation library opens the existing guided lessons. Local scenario and lesson progress remains browser-local.

## Hub integration

`index.html` and `lab.html` open the same original lab. The outer world interface provides recording, favorites, sharing, and navigation. Added files `hub.css` and `hub.js` reserve control space and disable the separate AI-guide/API affordances. No API keys, server files, private logs, or original proof records are included. The separate shared-room server and AI blueprint/voice/explanation services are not connected in this static edition. The dependent six-checkpoint atlas/AI journey is hidden; the standalone local physics lessons remain available.

Every original JavaScript module, simulation kernel, renderer, and copied asset is byte-for-byte unchanged. See `BUILD_ORIGIN.json` for source hashes and `THIRD_PARTY_NOTICES.md` plus the asset metadata files for credits and source restrictions.

Local HTTP/static checks and any browser verification are separate from human approval.
