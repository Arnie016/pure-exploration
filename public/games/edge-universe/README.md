# Thirty Steps Down — existing interactive edition

Recovered from Arnav’s existing `thirty-steps-down.html` source. This is the original 30-layer, 61-second Canvas 2D journey from the observable universe to a quark; it is not a newly generated remake.

## Controls

- Space: play or pause.
- Left/right arrows: previous or next layer.
- Drag the timeline or select a named layer.
- Playback speed: 0.5×, 1×, or 2×. Restart, loop, and fullscreen are available.

## Packaging and provenance

All drawings are rendered procedurally by the existing inline JavaScript. No third-party images, video, 3D assets, or audio are bundled. The original 55 MB MP4 is intentionally omitted. Optional typography loads Bricolage Grotesque, JetBrains Mono, and Newsreader from Google Fonts, with system fallbacks; no account or paid runtime service is required. The page remains functional without those fonts.

The only integration changes are a document/viewport wrapper, the shared capture-context script, space for the hub’s world controls, and a caption clarifying that this is an illustrative scale journey. Original simulation JavaScript is unchanged. This packaging note does not impose a new license on the recovered source.

Local syntax and HTTP checks are recorded separately; rendered browser and human review remain to be completed.
